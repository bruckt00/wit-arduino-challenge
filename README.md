# wit-arduino-challenge

An interactive Arduino challenge for the WiT Ada Lovelace Flagship Event, designed to inspire creativity, problem-solving, and hands-on learning through hardware, coding, and teamwork.

## Challenges

Each challenge includes materials, wiring instructions, a fill-in-the-blank
starter version to figure out yourself, and the full solution at the bottom.

| Challenge | Description |
| --- | --- |
| [Build a Reaction Game](build-a-reaction.md) | Wait for a random LED flash, then press the button as fast as you can. The Arduino measures your reaction time in milliseconds — fastest group wins! |
| [RGB Color Challenge](rgb-color-challenege.md) | Build a "color mixer" using an RGB LED and three potentiometers to recreate target colors like purple, orange, and teal. |

## Getting Started

1. Install the [Arduino IDE](https://www.arduino.cc/en/software).
2. Go to either the [Build a Reaction Game](build-a-reaction.md) or [RGB Color Challenge](rgb-color-challenege.md) page to start a challenge.
3. Gather the materials listed at the top of each challenge.
4. Follow the wiring instructions step by step.
5. Try the **Your Challenge** starter code first, then check your work against
   the **Full Code (Solution)** at the bottom.

Please follow the instructions carefully and have fun exploring the Arduino challenge!
